## Растровая графика
- Пиксель хранит интенсивности R, G, B. Пиксель — не квадратик, а значение функции в точке растровой сетки.
- **Глубина цвета** — бит на пиксель: 8-бит, 15/16 (high color), 24 (true color), 30/36/48 (deep color).
- Хранение компонент: битовые плоскости (устаревшее) или interleaved `RGB RGB RGB…`.
- Порядок пикселей: линейный (построчно) или **кривая Мортона (Z-order)** — меньше промахов кэша при доступе к соседям в 2D.

## Линейная алгебра
- Вектор — направление + длина; многие объекты (полиномы, изображения) ведут себя как векторы.
- Алгебра матриц изоморфна алгебре линейных операторов → матрицы = преобразования (растяжение, поворот).
- Линейное преобразование `y = Ax` всегда переводит начало координат в себя → **перенос не линейный**.
- Аффинное: `y = Ax + b`. Чтобы записать матрицей, вводят **однородные координаты** (добавляют 4-ю компоненту w):
  - вектор `(x, y, z, 0)`, точка `(x, y, z, 1)`;
  - точка − точка = вектор, точка + вектор = точка, вектор + вектор = вектор;
  - произвольное `(x, y, z, w)` → `(x/w, y/w, z/w, 1)` (перспективное деление).
- Матрица переноса 4×4: единичная с `(tx, ty, tz)` в последнем столбце.

## Проекции (Vulkan-конвенции)
- **Канонический объём вида Vulkan**: x,y ∈ [−1, 1], z ∈ [0, 1]; ось **+y направлена вниз**.
- Ортографический объём (l, r, t, b, n, f) → канонический: композиция переноса и масштаба:
```
        | 2/(r-l)   0        0         -(r+l)/(r-l) |
Ortho = | 0         2/(b-t)  0         -(b+t)/(b-t) |
        | 0         0        1/(f-n)   -n/(f-n)     |
        | 0         0        0          1           |
```
- Перспективная матрица (сжимает усечённую пирамиду в параллелепипед, w := z):
```
P = | n 0 0    0  |
    | 0 n 0    0  |
    | 0 0 f+n -fn |
    | 0 0 1    0  |
```
- **Перспективная проекция = Ortho · P**:
```
| 2n/(r-l)  0         -(r+l)/(r-l)   0          |
| 0         2n/(b-t)  -(b+t)/(b-t)   0          |
| 0         0          f/(f-n)      -fn/(f-n)   |
| 0         0          1             0          |
```
- Через угол обзора θ (вертикальный FOV) и аспект w/h (симметричный frustum):
```
| 1/((w/h)·tan(θ/2))  0             0         0         |
| 0                   1/tan(θ/2)    0         0         |
| 0                   0             f/(f-n)  -fn/(f-n)  |
| 0                   0             1         0         |
```
  (камера смотрит вдоль +z; после умножения делим на w = z.)
